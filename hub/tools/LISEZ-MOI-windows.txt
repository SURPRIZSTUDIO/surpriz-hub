SÜRPRIZ HÜB pour Windows
========================

1. Décompresse ce zip où tu veux (par exemple dans Documents).
   Si tu avais déjà le hub, remplace simplement l'ancien dossier.
2. Ouvre « {EXE} ».
   Si Windows affiche « Windows a protégé votre ordinateur » :
   Informations complémentaires › Exécuter quand même (une seule fois).
3. Clique « Installer » sur Toolkit, puis relance After Effects :
   Fenêtre › Extensions › Toolkit.

Ensuite, le hub se met à jour tout seul : un bandeau propose « Mettre à jour ».
